# KINETIC backlog

Generated 2026-09-30 from a multi-agent code audit (each bug below was confirmed by independent verifiers) plus feel/balance reviews and content-design proposals.
Already fixed in the same session: the stacked-geometry no-clip, glare/bloom (+ Glow / Brightness settings), bot weapon arsenal, and every high/medium audit bug (three only partially — see below). What remains is below.

## Content drop (Stormfront + Aerie) — built, known gaps

Built 2026-09-30: maps Stratos + Aerie; weapons Slipstream (smg, 6), Tempest (arc, 7), Javelin (rail, 8), Gale (gale, 9);
grenade types Vortex / Static / Kinetic / Smoke (G throws, X cycles); modes Escalation + King of the Hill (zones on every map).
Both design documents are summarised further down.

- **KOTH bots under-commit to the hill**: 13-17% of alive bot time inside the live zone (design target ~40%) — tune retreat/health rules near the zone.
- **Stratos lightning**: bots do not avoid the telegraphed strike zones.
- **Vortex**: the optional screen-space gravitational-lens warp was not built (violet vignette + shake instead).
- **Bots rarely throw special grenades** (static / kinetic especially); rates untuned.
- **Javelin in bot hands** is inaccurate (~2 hits per 11 shots in a 15 s sample); the first-person beam was widened after its last visual check.
- **Menu at 1280x720**: the time-limit row in Match Setup sits partly under the Back/Deploy footer.
- **Map pads**: new-weapon pads exist on every map; crates on Aerie pin kinetic/smoke specials.

## Follow-ups from the fix pass

- **Esc-resume pointer lock** (`ui-menu-escape-resume-not-a-user-gesture`, partial): Input no longer burns the lock attempt without a user gesture and a click on the canvas re-locks, but Esc-resume itself still needs that extra click.
- **Bot start node across a wall** (`aibrain-nearest-node-across-wall-start`, partial): NavGraph now prefers a visible nearest node and BotBrain rescues `startBlocked` bots; a bot that reaches a jump-pad node outside the 1.1 m trigger can still walk onto the pad by direct steering.
- **Dynamic draw calls** (`perf-bot-and-projectile-models-unbatched`, partial): bot weapons 8-18 -> 3 meshes, rockets 18 -> 5; bot bodies are still ~13 meshes each.
- **Startup hitch**: shader compiles are gone from play (first frame 592 ms -> 18 ms, program count constant), but the autotest still reports fps.min 4 from 200-700 ms gaps in the first ~0.3 s outside JS update/render (HUD/DOM first paint).
- **Glare polish**: close explosions still show bright white spark streaks (could be tinted orange); foundry furnace core saturates (intended).
- **Collision**: `CollisionWorld` inside-test has a ~10 cm false-positive sliver flush against one foundry box face (unreachable by the capsule centre in practice); NavGraph build is ~100-200 ms slower on ruins (inside-solid filtering).
- **Map data**: validator still warns about spawns near/inside solids on ruins and skyline and foundry's 800 solids (budget ~700); spawns inside solids are relocated at runtime, but the map data should be cleaned up.
